# Carte de visite Ignis Nova

Page unique, sans serveur ni base de données. Publiée via GitHub Pages.

## Fichiers

- `index.html` — la page. Le bloc `const FICHE` en haut contient les coordonnées.
- `logo-splash.mp4` / `logo-poster.jpg` — animation du logo et son image de secours
- `mascotte-salut.mp4` / `mascotte-poster.jpg` — le personnage et son image de secours

## Modifier les coordonnées

Deux possibilités :

1. Éditer `index.html` directement sur GitHub et changer le bloc `const FICHE`.
2. Ouvrir la page publiée, cliquer la roue crantée, saisir le mot de passe, modifier,
   puis « Télécharger le fichier » et remettre le fichier obtenu dans le dépôt.

## Les deux adresses

| Adresse | Pour qui |
|---|---|
| `.../` | les visiteurs — carte animée, enregistrement du contact |
| `.../?moi` | vous — QR code à faire scanner, à mettre sur l'écran d'accueil |

## Avertissement

Le dépôt est public : le mot de passe de la roue crantée est lisible dans le code
source. Il empêche un visiteur de tomber sur l'éditeur par hasard, rien de plus.
Ne réutilisez pas ce mot de passe ailleurs.
